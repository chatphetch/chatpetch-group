ตั้งรหัสผ่าน Admin

ใช้สำหรับบัญชี Google เดิมของคุณ เพื่อเพิ่มการเข้าสู่ระบบแบบ Email + Password โดยยังคงใช้ User/UID เดิม

กำลังตรวจสอบบัญชี...
กดปุ่มด้านล่างเพื่อเข้าสู่ระบบด้วย Google ของบัญชี Admin เดิม หลังจากนั้นจึงจะสามารถตั้งรหัสผ่านให้บัญชีเดิมได้
บัญชีที่กำลังตั้งรหัสผ่าน:
แนะนำให้ใช้รหัสผ่านอย่างน้อย 8 ตัวอักษร
หลังตั้งรหัสผ่านสำเร็จ ให้กลับไปที่หน้า Admin และเข้าสู่ระบบด้วย Email + Password
