    SERVICE DETAIL

    รายละเอียดบริการ

    หน้ารายละเอียดจะแสดงลักษณะงาน ปัญหาที่พิจารณา ความเหมาะสมของพื้นที่ และภาพอ้างอิงจากผลงานใน Repository

    OUR PROCESS

    ขั้นตอนการให้บริการ

    เริ่มจากการเข้าใจพื้นที่และลักษณะการใช้งาน ก่อนเลือกแนวทางและวัสดุที่เหมาะสม

    01 / SURVEY

    สำรวจหน้างาน

    พิจารณาสภาพพื้น ลักษณะพื้นที่ ปัญหาเดิม และเงื่อนไขการใช้งานจริง

    02 / CONSULT

    วิเคราะห์และให้คำปรึกษา

    ประเมินแนวทางระบบงานและวัสดุให้สอดคล้องกับวัตถุประสงค์ของพื้นที่

    03 / SYSTEM

    เลือกระบบที่เหมาะสม

    กำหนดระบบพื้นหรือแนวทางงานตามสภาพหน้างานและการใช้งาน

    04 / EXECUTION

    ดำเนินงาน

    วางแผนและดำเนินงานตามระบบ พร้อมติดตามรายละเอียดของหน้างาน
